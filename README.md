# 🚀 EXODUS — Humanity's Last Ship

### An Immersive 3D Sci-Fi Space Experience

**EXODUS** is a futuristic web experience centered around EXODUS-01, humanity's last generation ship, embarking on an interstellar journey toward the mysterious planet NOVA-7.

Explore a cinematic science-fiction environment featuring spacecraft visualization, atmospheric space scenes, mission telemetry, and immersive visual effects.

## ✨ Features

- 🚀 **3D Space Experience** — Explore a futuristic spacecraft and its environment.
- 🌌 **Cinematic Visuals** — Atmospheric space environments and immersive effects.
- 🪐 **NOVA-7 Exploration** — Discover the destination of humanity's journey.
- 📡 **Mission Telemetry** — Futuristic spacecraft monitoring and system information.
- 🎨 **Interactive Interface** — A visually engaging, sci-fi-inspired web design.
- 📱 **Responsive Design** — Designed to adapt to different screen sizes.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Three.js
